# 2026-11-22 — lean `agy` delegate context

Measured whether `--disable-slash-commands` and masking skills, plugins and
`mcp_config.json` in `delegate.sh`'s `bwrap` jail reduce the fixed input
context of an `agy` delegate.

## Method

Three one-word calls (`agy -p "Answer with the single word: ok" --model
gemini-3.8-flash-high --output-format json`) from this repository (with 0
configured MCP servers, 0 user plugins, 1 user skill and 16 builtin skills):

1. `full`: plain `agy -p`.
2. `no-slash`: adding `--disable-slash-commands`.
3. `lean-jail`: adding `--disable-slash-commands` and `bwrap` read-only empty
   masks over `~/.gemini/config/skills`, `~/.gemini/config/plugins`,
   `~/.gemini/config/mcp_config.json` (`{}`) and
   `~/.gemini/antigravity-cli/builtin/skills`.

Reproducible via `tools/fixed-context-agy.sh <root> [model]`.

## Data

| Run | Status | Input tokens | Output | Thinking | Delta vs full |
|---|---|---:|---:|---:|---:|
| `full` | `SUCCESS` | 11,926 | 131 | 130 | — |
| `no-slash` | `SUCCESS` | 11,925 | 149 | 148 | −1 (−0.0%) |
| `lean-jail` | `SUCCESS` | 11,139 | 169 | 168 | −787 (−6.6%) |

## Reading

- `--disable-slash-commands` alone prevents slash expansion in the prompt but
  does not strip skill descriptions from the system prompt.
- Masking `skills`, `plugins` and `mcp_config.json` read-only inside `bwrap`
  cuts **787 tokens per request** even on a clean machine with zero MCPs and
  zero plugins (~23.6k tokens over a 30-request TASK), and isolates `agy`
  delegates from any MCP servers or user plugins installed later.

## Decision

Added the read-only masks for `~/.gemini/config/{skills,plugins,mcp_config.json}`
and `~/.gemini/antigravity-cli/builtin/{skills,plugins}` to `delegate.sh`'s
`bwrap` jail, and added `tools/fixed-context-agy.sh`.

## To measure again

Re-run `tools/fixed-context-agy.sh <root>` after installing any `agy` MCP
server or plugin, or after an `agy` CLI update that adds a native `--tools` or
`--strict-mcp-config` flag.
